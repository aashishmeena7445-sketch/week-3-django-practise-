Authentication Dashboard System
Description

Authentication Dashboard System is a full-stack web application built using Django REST Framework (DRF), React.js, and MySQL. The project provides secure user authentication using JWT, role-based access control, protected routes, and complete CRUD operations through REST APIs.

Features
User Authentication with JWT
Secure Login and Authorization
Role-Based Access Control
CRUD Operations (Create, Read, Update, Delete)
REST API Development using DRF
React Frontend Integration
Protected Routes
MySQL Database Connectivity
Dynamic Dashboard
